# Frutas

Esta carpeta queda preparada para fotografías oficiales de frutas. Actualmente las ilustraciones de frutas son formas CSS originales (`src/components/FruitArt.jsx` y `src/styles.css`); no se han añadido fotografías.

Guarda aquí los originales aprobados. Las tarjetas de sabores buscan:

- `chirimoya.webp`
- `achachairu.webp`
- `maracuya.webp`
- `copoazu.webp`

Si una foto falta o no se puede cargar, la tarjeta conserva una reserva neutra con su nombre. No uses imágenes con licencias o procedencia sin verificar.

# Productos

Carpeta reservada para fotografías oficiales de los envases NATIV. El configurador busca estos nombres:

- `nativ-200ml.webp`
- `nativ-500ml.webp`
- `nativ-1l.webp`
- `nativ-2l.webp`

La presentación seleccionada determina la fotografía grande del configurador. Si el archivo todavía no existe o no carga, se muestra un panel neutro con un aviso discreto. Añade fotografías aprobadas directamente aquí; no se usan imágenes externas.
